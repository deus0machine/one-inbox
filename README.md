# One Inbox

Все почтовые ящики (Яндекс, Gmail, Mail.ru и любые с IMAP) в одном окне на Windows.
Программа сидит в трее, присылает уведомления о новых письмах и не требует ничего ставить, кроме Python.

*A tiny Windows tray mail client: all your IMAP inboxes (Yandex, Gmail, Mail.ru…) in one window, with notifications. Pure Python stdlib, no dependencies; the UI is a local page shown in an Edge app window.*

## Зачем
Надоело держать открытыми вкладки Яндекс Почты, Gmail и остальных? Thunderbird для этой задачи слишком тяжёлый и запутанный. One Inbox — небольшая программа, которая собирает «Входящие» всех ящиков в одну ленту.

## Возможности
- **Общая лента** писем со всех ящиков. У каждого ящика свой цвет, письма можно смотреть все вместе или по одному ящику.
- **Папки**: Входящие, Отправленные, Черновики, Спам, Корзина (общие для всех ящиков), а также собственные папки и ярлыки Gmail каждого ящика.
- **Действия с письмом**: прочитано или непрочитано, отметка ★, спам или не спам, удалить, восстановить, удалить навсегда. Клавиша `Delete` отправляет письмо в корзину.
- **Поиск** по теме и отправителю, кнопка «Загрузить ещё» для старых писем, вложения скачиваются.
- **Трей и уведомления.** При закрытии окна программа остаётся в трее, раз в 2 минуты проверяет почту и показывает уведомление Windows о новых письмах. Уведомления можно выключить.
- **Счётчик новых писем** на иконке в панели задач.
- **Картинки как в Gmail**: внешние изображения по умолчанию скрыты, отправитель не узнает, что письмо открыто. Можно показать один раз или всегда показывать от конкретного отправителя.
- Светлая и тёмная тема (по системной).

## Требования
- Windows 10 или 11
- [Python](https://www.python.org/downloads/) 3.10 или новее. Сторонние пакеты не нужны: только стандартная библиотека.
- Microsoft Edge (есть в Windows) или Google Chrome. Он используется как окно программы.

## Установка
```
git clone <адрес репозитория>
cd one-inbox
python install_shortcut.py
```
Скрипт создаст ярлык «Почта» на рабочем столе и в меню «Пуск». Дальше программа запускается ярлыком.

Без ярлыков тоже можно: `pythonw app.py` (или `start.bat`). Если добавить `--tray`, программа стартует сразу свёрнутой в трей.

## Подключение ящиков
Обычный пароль от почты не подойдёт, нужен **пароль приложения**. Он даёт доступ только к почте, и его можно отозвать в любой момент.

**Яндекс**
1. Яндекс Почта → ⚙ → «Все настройки» → «Почтовые программы» → включить «С сервера imap.yandex.ru по протоколу IMAP» и выбрать «Пароли приложений и OAuth-токены».
2. [id.yandex.ru](https://id.yandex.ru/security/app-passwords) → «Безопасность» → «Пароли приложений» → «Почта» → создать пароль.

**Gmail**
1. Включить [двухэтапную аутентификацию](https://myaccount.google.com/signinoptions/twosv).
2. [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) → создать пароль приложения (16 букв).

Если страница пишет «Эта настройка недоступна для вашего аккаунта», значит, не включена двухэтапная аутентификация или это рабочий аккаунт, где пароли приложений запретил администратор.

**Mail.ru**: Настройки → «Безопасность» → «Пароли для внешних приложений».

**Другие почтовые сервисы**: укажи IMAP-сервер вручную в окне добавления ящика (порт 993, SSL).

Дальше в программе «+ Добавить ящик» → адрес и пароль приложения. Перед сохранением программа проверяет, что вход работает.

## Использование
| Действие | Как |
|---|---|
| Открыть окно | клик по конверту в трее или повторный запуск ярлыка |
| Меню | правый клик по конверту в трее |
| Выйти совсем | меню трея → «Выход» (крестик окна только сворачивает в трей) |
| Уведомления вкл/выкл | кнопка 🔔 слева внизу в окне или пункт в меню трея |
| Переименовать или убрать ящик | навести на ящик слева → ✎ или × |

На Windows 10 новая иконка в трее сначала прячется под стрелкой ^ у часов. Её можно перетащить на панель.

## Безопасность и приватность
- Пароли приложений хранятся в `data/accounts.json` в зашифрованном виде (Windows DPAPI). Расшифровать их может только твоя учётная запись Windows на этом компьютере.
- Соединения с почтовыми серверами идут только по TLS, сертификат проверяется (стандартный `imaplib` по умолчанию этого не делает, здесь проверка включена явно).
- Интерфейс — локальная страница на `127.0.0.1` со случайным портом и одноразовым ключом доступа на каждый запуск. Из сети к ней не подключиться, а другие сайты в браузере не могут ни прочитать её, ни отправить ей команды.
- Письма показываются в изолированном iframe без скриптов. Внешние картинки, шрифты и стили блокируются политикой CSP, пока ты не разрешишь их показ.
- Программа никуда не отправляет данные, кроме твоих почтовых серверов. Единственное исключение: если системный DNS не может найти почтовый сервер (так бывает при некоторых VPN), его адрес запрашивается у `dns.google` по HTTPS. Сертификат сервера и в этом случае проверяется по настоящему имени.

Все личные данные (ящики, настройки, лог, профиль окна Edge) лежат в папке `data/`, она в `.gitignore`.

## Как это устроено
```
app.py            HTTP-сервер на 127.0.0.1, API для окна, фоновая проверка почты, запуск/выход
mail_client.py    IMAP: подключение, папки, список писем, разбор писем, действия
secrets_store.py  шифрование паролей через Windows DPAPI
tray.py           иконка в трее, меню, уведомления (Shell_NotifyIcon через ctypes)
taskbar.py        своя группа и иконка на панели задач, счётчик на иконке
icons.py          иконки, нарисованные кодом (конверт, значок с числом), сборка .ico
shortcut.py       ярлыки .lnk с AppUserModelID
winapi.py         минимальные COM-обёртки для ctypes
ui/               интерфейс: index.html, app.js, style.css
```
Окно программы — Microsoft Edge в режиме приложения (`--app`) с отдельным профилем, в котором выключены менеджер паролей, автозаполнение и переводчик. Окну назначается собственный AppUserModelID, поэтому на панели задач это отдельное приложение «Почта» со своей иконкой, а не Edge.

## Ограничения
- Только Windows.
- Письма пока нельзя писать и отправлять: программа читает почту и наводит в ней порядок.
- Новая почта проверяется раз в 2 минуты, без мгновенного push (IMAP IDLE).
